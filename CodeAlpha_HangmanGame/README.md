# CodeAlpha Hangman Game

A beginner-friendly text-based Hangman game built with Python.

## Features
- Chooses a random word from five predefined words.
- Accepts one letter per turn.
- Allows up to six incorrect guesses.
- Checks invalid and repeated guesses.

## Requirements
- Python 3.8 or newer
- No external packages required

## Run
```bash
python main.py
```

## Concepts used
`random`, lists, strings, `while` loops, `if-else`, functions, and input/output.
